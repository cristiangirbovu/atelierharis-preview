# Atelier Haris, site de prezentare și catalog (preview)

Site static pentru Atelier Haris, construit de AMPLIO. Aceasta este versiunea de previzualizare; adresa finală va fi atelierharis.ro.

- Textele și datele: `src/content.js` (contact, firmă, livrare, produse), `src/legal.js`
- Generatorul: `src/build.js` (`node src/build.js` pentru preview, `node src/build.js --prod` pentru atelierharis.ro)
- Stil și script: `assets/style.css`, `assets/app.js`
- Fonturi: Cormorant Garamond și Lato (SIL Open Font License), găzduite local în `assets/fonts`
