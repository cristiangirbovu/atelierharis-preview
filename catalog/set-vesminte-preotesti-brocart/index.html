Descriere

Set complet: felon, epitrahil, brâu, rucavițe și bederniță, în același model brodat. Fiecare piesă se brodează după confirmarea comenzii, în culoarea aleasă de dumneavoastră.

Materiale

Brocart, fir metalic, căptușeală de bumbac.

Îngrijire

Curățare chimică delicată. Se păstrează întins sau pe umeraș lat, ferit de lumina directă.

Adaptări

Putem schimba culoarea firului, dimensiunile sau putem adăuga o inscripție. Scrieți-ne ce doriți, iar prețul adaptării vi-l comunicăm înainte de execuție.
